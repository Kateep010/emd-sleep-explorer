01為什麼睡眠訊號需要 EMD？

傅立葉分析把訊號展開成固定頻率、固定振幅的正弦波之和。這件事隱含兩個假設：訊號是線性的（波形可以疊加而不互相影響）而且平穩的（統計性質不隨時間改變）。睡眠腦波兩者都不滿足：

深入說明
  • 非平穩：N2 期的紡錘波（sleep spindle，11–16 Hz）只持續 0.5–2 秒；K 複合波是單一的瞬態事件；從 N2 進入 N3 時，慢波逐漸變大變慢。
  • 非線性：神經元集體放電產生的波形不是完美正弦波，常常「上升快、下降慢」。傅立葉必須用一堆諧波（2 倍頻、3 倍頻……）拼出這種形狀，但那些諧波在生理上並不存在。

EMD 的想法完全不同：它不問「這個訊號由哪些正弦波組成」，而是問「這個訊號自己的振盪有幾種時間尺度」。它把訊號拆成少數幾個本質模態函數（Intrinsic Mode Function, IMF），每個 IMF 都是振幅與頻率可隨時間改變的單一振盪，因此可以用 Hilbert 轉換算出瞬時頻率。下面的小實驗就是黃鍔 1998 年論文裡的經典例子。

02演算法拆解：篩選（sifting）

EMD 的核心是一個叫 sifting（篩選） 的迭代程序。一個 IMF 必須滿足兩個條件（Huang et al., 1998）：

  1. 整段訊號的極值個數與零交越個數相等，或最多差 1；
  2. 在任一時間點，由局部極大值構成的上包絡線與局部極小值構成的下包絡線，其平均值為 0。
深入說明

篩選就是不斷把「包絡線平均」從訊號裡扣掉，直到剩下的部分滿足上面兩個條件：

h1(t) = x(t) − m1(t)，  h11(t) = h1(t) − m11(t)，  … 直到 h1k 是 IMF，記為 c1(t)

什麼時候停？黃鍔建議用相鄰兩次篩選結果的標準差：

SD = Σt |h1(k−1)(t) − h1k(t)|² / Σt h1(k−1)(t)²  <  0.2 ～ 0.3

抽出 c1 後，殘差 r1 = x − c1 再重複同樣的程序得到 c2、c3……直到殘差變成單調函數（沒有足夠的極值可以畫包絡線）。最後 x(t) = Σ ci(t) + rn(t)，分解是完備的：所有 IMF 加上殘差可以完全重建原訊號。

包絡線用三次樣條（cubic spline）通過極值點；訊號兩端沒有極值可以參考，我們採用 Rilling 等人的鏡像延伸把最靠近邊界的極值對稱反射出去，避免包絡線在邊緣「甩尾」。這是實作 EMD 最容易被忽略、但影響最大的細節之一。

04Hilbert 譜 vs. 傅立葉頻譜圖

對每個 IMF 做 Hilbert 轉換，得到解析訊號 z(t) = c(t) + i·H[c(t)] = a(t)·eiθ(t)，瞬時振幅 a(t) 與瞬時頻率 ω(t) = dθ/dt。把所有 IMF 的 (t, ω, a²) 疊到時間–頻率平面，就是 Hilbert 譜（Hilbert–Huang Transform, HHT）。它與短時傅立葉（STFT）頻譜圖的差別在於：STFT 的時間解析度與頻率解析度互相牽制（視窗 2 秒 → 頻率解析度只有 0.5 Hz，且任何事件都被抹成 2 秒寬），而 Hilbert 譜的頻率是逐點算出來的，短暫的紡錘波會呈現為一道清楚的短線。

傅立葉譜告訴你「整段 30 秒內某個頻率的能量有多少」；Hilbert 邊際譜的意義是「某個頻率曾經出現的機率有多高」（Huang et al., 1998）。對一個 30 秒裡只出現兩次、各 1 秒的紡錘波，兩者的解讀完全不同。

05模態混疊與集成經驗模態分解（EEMD）

EMD 最出名的弱點是模態混疊（mode mixing）：當一個高頻振盪只間歇出現（例如紡錘波），有它的時段極值密集、沒它的時段極值稀疏，同一個 IMF 就會一下子裝著 14 Hz、一下子裝著 1 Hz；反過來，同一個尺度也可能被拆到不同 IMF。這正是睡眠腦波最常見的情況。

深入說明

Wu 與 Huang（2009）的解法很巧妙：在訊號上加入白噪音再分解，重複很多次，把結果平均。白噪音均勻填滿整個時間–頻率平面，提供一把「均勻的尺」讓每個時段的極值密度一致；而不同次試驗的噪音彼此獨立，平均之後互相抵消，殘留噪音的量級為 ε/√N。這就是 EEMD。代價是運算量乘以 N，而且各次分解的 IMF 相加不再完全等於原訊號——後來的 CEEMDAN（Torres et al., 2011）就是為了修正這一點。

06從 IMF 到自動睡眠分期

睡眠分期是把整夜的 PSG 每 30 秒判成 W / N1 / N2 / N3 / REM 之一。人工判讀費時且判讀者之間一致性有限，因此自動分期是睡眠研究的長期課題。Hassan 與 Bhuiyan（2016, 2017）的作法是把單導程 EEG 用 CEEMDAN 或 EEMD 拆成 IMF，對每個 IMF 計算平均、變異數、偏態、峰度等統計特徵，再交給集成式分類器（bagging、RUSBoost）；Liu 等人（2021）也用 EEMD 特徵做單導程自動分期。這些工作的共同邏輯是：IMF 是資料自適應的頻帶，能比固定的濾波器頻帶更貼近每一段訊號真正的振盪成分。

09與 AI 討論的紀錄、設計決策與限制

這個網站是在 Claude Code 的協助下完成的。以下整理製作過程中真正影響設計的問題與結論，以及我們自己驗證過的事實。

為什麼不用 FFT 或小波轉換就好？

FFT 假設平穩、線性，對 30 秒的睡眠 epoch 只能給「平均」頻譜，看不到紡錘波何時出現；小波雖然有時頻解析度，但基底是預先選定的（母小波），解析度仍受測不準原理限制。EMD 的基底由資料決定，IMF 的瞬時頻率是逐點的。代價是 EMD 沒有封閉的數學理論（沒有唯一性與收斂性的證明），這是它最常被批評的地方——所以我們在第 02 節把每一步都攤開來讓人檢查。

篩選的停止準則怎麼選？我們實際比較了什麼？

Huang 1998 用 SD 在 0.2–0.3；2003 年又提出 S-number 準則（連續 S 次篩選極值與零交越數相等或差 1）。我們的實作兩者都支援（sdThreshold、sNumber），並加上 maxSift = 50 的上限避免「過度篩選」——篩太多次會把 IMF 磨成振幅固定的純調頻訊號，失去物理意義。第 02 節可以直接切換 SD 門檻觀察篩選次數與 IMF 的差別。

邊界效應怎麼處理？

最早的版本只用自然三次樣條，包絡線在訊號兩端會劇烈甩動，錯誤逐階累積到低頻 IMF。改用 Rilling 等人的鏡像延伸（把最靠近兩端的 2 個極值對稱反射出去）後問題明顯改善。這也是為什麼 Hilbert 瞬時頻率我們在計算平均時捨棄前後各 5% 的樣本。

模態混疊真的會在睡眠腦波裡發生嗎？

會，而且非常典型。紡錘波正是「間歇出現的高頻振盪」，第 05 節用合成訊號重現了 Wu 與 Huang 描述的現象；在第 03 節的真實 N2 片段，若用 EMD，IMF2 常常在紡錘波之間的空檔混入較慢的背景活動，切換成 EEMD 後會乾淨許多。這解釋了為什麼睡眠分期的文獻幾乎都用 EEMD／CEEMDAN。

IMF 就等於 δ、θ、α、σ、β 頻帶嗎？

不是。IMF 是資料自適應的，同一個 IMF 的瞬時頻率在 30 秒內可能從 3 Hz 漂到 8 Hz；不同 epoch 的「IMF 3」也不一定對應同一個頻帶。本站用能量加權的平均瞬時頻率把 IMF「暫時」歸到傳統頻帶只是為了方便閱讀。做分類時要特別小心「IMF 編號對齊」的問題——這也是 EEMD 固定模態數、MEMD 對齊多通道的動機之一。

第 06 節的分期示意為什麼只有 16 個片段？準確率能相信嗎？

16 個片段是為了讓瀏覽器能即時算完整條流程（EMD 每個 epoch 約 1–3 毫秒）。留一法最近質心的準確率只能說明「這兩個特徵有沒有區分力」，不能推論到真實效能；正式研究用數千個 epoch、多位受試者與交叉驗證，而且 N1 期在人工判讀之間的一致性本來就低。

資料為什麼選 Sleep-EDF SC4002E0？

它是課程 Week 1 作業指定的公開資料，我們已在先前作業用 YASA 做過自動分期（準確率 84.2%、κ = 0.79），對這位受試者的整夜結構有把握。片段挑選避開階段邊界、排除 >150 µV 的雜訊；清醒期另外排除振幅 >80 µV 的眼動／汗液漂移片段，否則 EMD 的能量會被 0.3 Hz 的漂移主導。

部署：為什麼是 GitHub Pages 而不是 Zeabur？

作業原本要求部署到 Zeabur。查閱 Zeabur 官方文件（2026 年 9 月）後確認其「共享叢集」已停止服務，新帳號必須先綁定付費的專用伺服器才能建立專案；2026-09-23 以 Zeabur CLI 實測，建立專案時 API 回覆「Shared clusters are deprecated. Please rent a Server」，最便宜的伺服器為每月 3 美元。因此改為雙平台：GitHub Pages（主要網址）與 Cloudflare Workers（emd-sleep-explorer.emd-sleep-explorer.workers.dev，以 wrangler.jsonc 靜態資產模式部署）。repo 內同時保留 zeabur.json 與一鍵腳本 tools/deploy_zeabur.sh，租用伺服器後即可部署，不需修改任何檔案。本站是純靜態網站，不需要任何後端。

我們怎麼確認自己寫的 EMD 是對的？

兩層驗證。第一層是有解析解的單元測試（tests/test_emd.mjs）：Bluestein FFT 對照直接 DFT、Hilbert 轉換對純音給出正確的瞬時頻率與振幅、EMD 完備重建（誤差 10⁻¹⁴）、雙音分離、模態混疊下 EEMD 優於 EMD。第二層是與 Python 套件 PyEMD 在同樣 16 個真實 epoch 上交叉比對（docs/validation.md）：用本站預設的 Huang 1998 SD 準則時，前三階 IMF 的相關係數中位數 0.69；把 PyEMD 額外的「極大值全為正、極小值全為負」條件也加進來（strictExtrema 選項）後升到 0.83，高、低頻合計的相關係數 0.87／0.89。結論：差異來自停止準則而非實作錯誤，而且 PyEMD 多篩幾次會把 IMF1 的頻率系統性推高，正是「過度篩選」的實例。

整夜的結果說明了什麼？

第 07 節把整夜 1128 個 epoch 全部做 EMD 與 EEMD。只用「δ 頻帶 IMF 能量占比」與「訊號 RMS」兩個特徵、最近質心分類器，留一法準確率 68%、κ 0.58，N3 幾乎全對、N1 幾乎全錯。把 10 個摘要特徵交給 k-NN 後升到 83%；改用 EEMD 特徵（模態對齊、σ／α 能量不再幾乎為 0）再升到 84.5%、κ 0.79，與 Week 1 作業用 YASA（數十個頻譜特徵 + LightGBM）在同一位受試者得到的 84.2%、κ 0.79 相當。這說明 IMF 特徵確實蘊含了睡眠結構的主要資訊，而且 EEMD 對「特徵對齊」的幫助是可量化的——正是 Hassan 與 Bhuiyan 系列論文走的路。但這是單一受試者內的留一法，相鄰 epoch 高度相關，數字比跨受試者驗證樂觀。

已知限制
  • EMD 沒有解析理論，結果對取樣率、雜訊、停止準則與邊界處理都敏感。
  • EEMD 的運算量是 EMD 的 N 倍；在瀏覽器裡 200 次集成約需 1 秒。
  • Hilbert 瞬時頻率在振幅接近 0 的時段會發散，Hilbert 譜在這些點不可靠。
  • 只用單一受試者的單一導程；Fpz-Cz 靠近前額，易受眼動影響。
